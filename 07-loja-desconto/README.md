# 07 — Loja com desconto

Loja online com várias regras:

- 10% de desconto com cupom ou compra acima de R$ 500
- cliente premium tem frete grátis
- cliente inadimplente não recebe desconto nem frete grátis

O programa também calcula o frete pela distância em km.

```bash
python loja.py
```

**Conceitos:** várias condições, cálculo de valores
