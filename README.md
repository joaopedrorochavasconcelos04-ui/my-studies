# my-studies

Repositório de aprendizado de Python. Cada pasta é um exercício, do mais simples ao mais elaborado.

## Como usar

Entre na pasta do exercício e rode o arquivo `.py` no terminal:

```bash
python nome_do_arquivo.py
```

Alguns programas pedem dados no teclado (`input`). Outros só imprimem o resultado.
